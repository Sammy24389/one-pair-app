# OpenPigeon: selected Android route

The user selected Android first, with browser and PC integration deferred. Padi hosts the Madrid extension of a separately installed OpenPigeon application. OpenPigeon retains its branding, games, graphics and updates. Padi does not bundle its games or assets.

Official host instructions: https://github.com/OpenBubbles/OpenPigeon/blob/wordhunt/Integration.md

The earlier v1-final-agpl export investigation is superseded. Its source cache is reference material only and is not shipped. Private or noncommercial use does not grant permission to redistribute current restricted assets; the separate-app route avoids doing that.

See OPENPIGEON-ANDROID.md for the implementation contract and device verification checklist, and ../android/MADRID-NOTICE.md for native interface attribution.
