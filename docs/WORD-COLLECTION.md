# Word collection contract

## Outcome and scope
Three original, tactile 2D word games for the existing two-to-four-device peer group. No GamePigeon artwork, branding or game code. English, offline, lengths 3–8. Six accepted distinct words per player, or explicit Finish. Length-based points. Everyone receives identical deterministic puzzle/rack and independent Word Bites geometry, found words and move allowance. 62 deterministic puzzle/rack variants, including planted six-letter trails on generated Hunt boards. No timer: no host clock trust or background deadline loss. All seats finish before winner calculation; tied top scores draw. These are friendly shared-board games: words are visible and peers can inspect the puzzle/state; this is not a hidden-information tournament or anti-cheat service.

## Rules and interface
`WORD_INFO`, `createWordData`, `validWordData`, `moveWord`, default `WordGames` use game-types contracts. Root router owns actor/room/version checks, clone and version increment. Word module mutates only accepted moves. Hunt uses unique adjacent indexes including diagonals. Anagrams uses unique six-rack indexes. Bites uses eight fixed-shape pieces on a six-square grid; shifting preserves shape and cannot overlap or leave the board, capped at forty accepted shifts per player. Submit contiguous left-to-right or top-to-bottom occupied indexes; full piece selection is not required. Invalid inputs do not consume a word/move. Snapshots validate sequential turn/completion coherence, terminal score winners, last-word consistency and Hunt/Anagrams word formability. Bites snapshot words are checked against the available letter multiset; historical spatial placement is validated during each move and relies on the existing authenticated host transition history rather than reconstructed from the current board. Score, dictionary, duplicate, geometry and length validation happen in deterministic rules, not UI alone.

## UI and accessibility
Warm paper scoreboard, green recessed board, raised cream letter tiles, visible selected path, clear submit/undo/clear controls, dictionary feedback and explicit Finish. Touch tracing plus individually focusable buttons. Bites supports drag from first letter and select-then-destination alternative. Minimum forty-pixel mobile cells; reduced-motion transitions disabled. Turns and accepted word reset transient selections. Waiting/spectator controls disabled. Scores include completion state and word count. Board scales to phone width; desktop capped for legibility.

## Data and deployment
Dictionary source/license/snapshot/hash in src/assets/words/README.md; static bundled raw text with lazy sorted-array binary search (avoids a 148k-entry Set), no API, accounts, new package or runtime network. The broad dictionary includes uncommon/offensive words and is not a moderated vocabulary. All peers should use the same release. At most 24 stored found words and 32 pieces per game. Persistence/transfer reuse existing bounded party state. No server/database migrations, cloud compute or new endpoints. P2P availability and application-level anti-cheat limitations remain unchanged. Dictionary bundle adds approximately 1.3 MB source text (compression reduces delivery); route should be loaded with game collection.

## Acceptance / verification
Rules tests cover malformed state and moves, adjacency/reuse/counts, dictionary rejection, duplicates, immutability via caller clone, actual Bites spatial words/collisions/bounds, move cap, seat completion and ties. UI tests cover tile input, submit/finish, disabled waiting controls, accessible non-drag movement and collision feedback. Root integration must typecheck, run full suite/build, and visually exercise phone/desktop plus two peers. Physical network and touch tests remain release checks rather than evidence from jsdom.

Gesture revision: valid words submit on pointer release in Hunt, Anagrams and Bites trace mode. Dimensional tiles and trays use CSS shadows/materials rather than a WebGL scene. Pointer capture keeps touch traces on the board; a synchronous transient path reference prevents React update timing from dropping the final letters. Pointer cancellation and window blur discard unfinished traces. Manual submit remains the keyboard/tap alternative. Ten UI tests cover release-to-submit, cancellation, keyboard composition and Bites piece movement. New rendered-device verification remains pending.
